# OpenFetch Site

Site estático do OpenFetch, preparado para GitHub Pages.

## Publicação

1. Envie estes arquivos para a raiz do repositório do site.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **GitHub Actions**.
4. Faça push para a branch `main` para iniciar o workflow.
5. Acompanhe o resultado na aba **Actions**.

## Downloads

O instalador do OpenFetch 0.1.0 para Windows x64 está disponível como anexo da [GitHub Release](https://github.com/jhonnyboy-sgbr/OpenFetch-0.1.0/releases/tag/v0.1.0). Ele não possui assinatura digital; a página de downloads avisa que o Windows pode mostrar um alerta de editor desconhecido e informa o SHA-256 do arquivo. Publique novas versões somente após conferir o pacote, o tamanho, o hash e o link da release.

## Manutenção

- Teste links e páginas antes de publicar.
- Mantenha a documentação alinhada ao comportamento real do aplicativo.
- Não inclua segredos, tokens ou dados pessoais neste repositório.
